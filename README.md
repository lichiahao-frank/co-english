# 小兔子英語陪練 🐰

每天 20 分鐘的英語聽力與口說練習 app。30 天後的目標：去美國時，**搭飛機、飯店 check in/out、餐廳點餐、跟人 small talk** 都能自己來。

目前已完成**全部功能 + Day 1〜7 的課程內容**。

---

## 一分鐘看懂這個 app

打開後每天就做五件事，總共 20 分鐘：

| | 步驟 | 做什麼 |
|---|---|---|
| 3 分 | 🌤️ 暖身回想 | 先看中文自己說，再看答案。系統會自動安排該複習哪幾句 |
| 5 分 | 🎧 今日聽力 | 先不看字聽對話 → 答 2 題 → 再看逐句對照 |
| 5 分 | 🗣️ 跟讀模仿 | 聽一句、說一句，可以錄下來聽自己的聲音 |
| 5 分 | 🎭 情境實戰 | 扮演旅客跟店員／路人對話，選你想說的話 |
| 2 分 | 🌙 今日收尾 | 30 秒即興，然後蓋護照章、拿胡蘿蔔 |

**沒時間的時候**按首頁的「只有 8 分鐘？用迷你模式」，只做暖身＋跟讀，**連續天數照算**。

### 關於口說，這個 app 的立場

- **不糾正腔調，不給發音分數。** 台灣腔的英文在美國完全溝通得來。
- 開口檢查只看「關鍵字有沒有說到」，而且刻意放寬：`th` 說成 `s`、`v` 說成 `w`、`r`/`l` 不分、字尾子音省略，**一律算通過**。
- 回饋只有兩種：「關鍵字都說到了 ✓」或「再試一次，記得說到 ○○」。沒有百分比、沒有分數、沒有「不標準」這種字眼。
- 覺得有壓力的話，到設定把「開口檢查」整個關掉，改用錄音回放一樣有效。

## 怎麼在電腦上跑

需要先裝 [Node.js](https://nodejs.org/)（LTS 版就好）。然後在這個資料夾打開終端機：

```bash
pnpm install
```

```bash
pnpm dev
```

跑起來後開瀏覽器到 http://localhost:5173 。要停止就在終端機按 `Ctrl + C`。

### 試用的時候

- **要測聲音和麥克風，請用你自己的 Chrome 開 http://localhost:5173** ，其他瀏覽器的支援度不一定完整。
- 第一次會先走三頁引導，然後從 Day 1 開始。
- 想**直接跳到某一天**看內容（例如 Day 3 的餐廳點餐），按 `F12` 打開 Console，貼上這行按 Enter：

```js
const p = JSON.parse(localStorage.getItem('bunny-english-progress-v1')); p.currentDay = 3; localStorage.setItem('bunny-english-progress-v1', JSON.stringify(p)); location.reload()
```

  把 `3` 換成 1〜7 任一天。
- 想**整個重來**：設定頁（右上齒輪）→ 最下面「清空所有進度」。

## 怎麼讓她在 Samsung 手機上用

手機要用麥克風，**必須是 https 網址**，所以要先部署上線。最簡單是 Vercel（免費）：

```bash
npx vercel
```

第一次會要你登入、問幾個問題，一路按 Enter 用預設值即可。它會給你一個網址，例如 `https://bunny-english-xxx.vercel.app`。

之後每次改完內容要更新線上版：

```bash
npx vercel --prod
```

> ⚠️ **部署等於公開上網**。這個 app 沒有任何個人資料（進度和錄音都只存在手機裡，不會上傳），所以風險很低，但網址拿到的人都能打開。

### 裝成手機 app

把網址傳給她，請她用 **Chrome** 打開（不要用三星內建瀏覽器，見下方限制），然後：

右上角 `⋮` → 「安裝應用程式」或「加到主畫面」

裝完後桌面會出現小兔子圖示，打開就是全螢幕，跟一般 app 一樣。

### 裝成電腦 app

用 Chrome 或 Edge 打開網址，網址列右邊會出現一個「安裝」圖示，按下去就會變成獨立視窗的桌面程式。

## ✅ 實機驗收清單（這部分只有真的拿手機才能確認）

我在電腦的 Chrome 上把整個流程跑過一遍都正常，但**手機的麥克風權限與語音引擎沒辦法在我這邊測**。請她第一次用的時候照這張表確認一遍：

- [ ] 網址用 **Chrome** 打開，頁面正常顯示小兔子
- [ ] 能「安裝應用程式／加到主畫面」，桌面出現圖示
- [ ] 進入 Day 1 →「今日聽力」→ 按「播放對話」**聽得到英文**
- [ ] 如果沒聲音：到「設定 → 英語聲音」換一個試試
- [ ] 「跟讀模仿」按「換我說說看」→ 手機**跳出麥克風授權**，按允許
- [ ] 說一句話後，看得到「我聽到你說：⋯⋯」
- [ ] 按「也想錄下來聽聽自己的聲音」→ 錄完能**播放聽到自己**
- [ ] 走完五步驟，最後出現「Day 1 完成！」和護照蓋章
- [ ] **關掉 app 再打開**，首頁顯示的是 Day 2、胡蘿蔔數還在
- [ ] 設定頁的「這台裝置可以做什麼」三項都是 ✓

最後一項如果有 ✕，那台手機就是不支援該功能，app 會自動隱藏它、其他練習照常可用。

## 已知限制（都查證過）

| 限制 | 說明 |
|---|---|
| **iPhone 不建議裝成主畫面 app** | iOS 把網頁裝成全螢幕 app 之後，麥克風和語音辨識有 WebKit 的已知問題（錄一次之後就失效，要重開機）。iPhone 請**直接用 Safari 開網址**，功能才正常。這也是當初選定以 Samsung 為主的原因。 |
| **三星內建瀏覽器只有部分支援** | Samsung Internet 的語音辨識支援不完整。**請用 Chrome**。app 偵測到不支援時會自動隱藏「開口檢查」，改用錄音，不會壞掉。 |
| **朗讀用的是手機內建語音** | 免費、可調速、離線可用，但少了真人的連音和語調。所以每天最後附了一個 YouTube 連結當延伸聽力（想練再練，不算在 20 分鐘內）。 |
| **錄音只保留 7 天** | 超過會自動清掉，免得佔滿手機空間。每天收尾的 30 秒即興會特別存起來。 |
| **進度只存在那台手機** | 不需要帳號、不會上傳。換手機前請到「設定 → 匯出進度」存成檔案，新手機再匯入。 |

## 怎麼補上 Day 8〜30 的內容

課程內容和程式是分開的，**不用動程式**。

1. 複製 `src/content/days/day07.ts`，改名成 `day08.ts`
2. 把裡面的內容換掉（`day: 8`、標題、5 個句型、對話、2 題理解題、分支對話、即興題）
3. 打開 `src/content/index.ts`，照現有的樣子多加兩行 import 和加進 `DAYS` 陣列

每個欄位的意思在 `src/content/types.ts` 裡都有中文註解。

**句型的 `id` 一定要唯一**（例如 Day 8 就用 `d8-1` 到 `d8-5`），間隔複習是靠這個 id 追蹤的。

## 程式結構

```
src/
├─ content/          課程內容（要改內容只需要動這裡）
│   ├─ types.ts      每個欄位的中文說明
│   ├─ index.ts      天數索引 + 句型小抄
│   └─ days/         day01.ts … day07.ts
├─ state/            進度、連續天數、胡蘿蔔、間隔複習、本機儲存
├─ audio/            朗讀、錄音、開口檢查（寬鬆比對寫在 recognition.ts）
├─ components/       小兔子 SVG、護照、共用按鈕
└─ screens/          九個畫面
```

技術：React + TypeScript + Vite + Tailwind CSS + PWA。沒有後端、沒有 API 金鑰、沒有月費。

### 遊戲化怎麼運作

- **胡蘿蔔**：每完成一步 +5，完成一整天 +10（迷你模式 +6）
- **小兔子成長**：60 / 170 / 320 / 520 根胡蘿蔔各解鎖一樣旅行裝備（背包 → 相機 → 墨鏡）
- **護照集章**：30 格，每 7 天換一座城市（舊金山 → 洛杉磯 → 紐約 → 波士頓）
- **補休卡**：每完成 7 天發一張，漏一天不會讓連續天數歸零（最多存 3 張）
- **間隔複習**：每句學完後 1 天、3 天、7 天、14 天、30 天各複習一次；說得出來就往後排，忘了就拉回第一階

這些數字都在 `src/state/store.ts` 最上面，想調整直接改。

## 對 30 天成果的誠實說明

20 分鐘 × 30 天 = **10 小時**。以國高中英文底子、但不敢開口的起點，10 小時可以合理期待：

- ✅ 四大情境（機場、飯店、餐廳、基本寒暄）的常見問答能應對
- ✅ 聽到練過的句型能即時反應
- ✅ 敢開口，聽不懂時會用救援句把對話撐住

但**不保證**真正「流暢」的自由 small talk——那需要數百小時的實際互動。這份課程的設計是把 10 小時集中在最高頻、最可預測的情境上，讓她到了美國真的敢開口、真的能把事情辦完。
